# Rat King owned primitives

Generated by `pnpm --filter pi-ratking tui:frames`. Edit the examples in `scripts/frames.ts`, not these frames.

Inline atoms return one styled string; block primitives return lines. Pass atoms to Header, Footer and Box. The view owns data decoding; primitives own only rendering. `tui.ts` retains compatibility helpers for existing consumers.

## Text

Fit a styled line while reserving its suffix.

Props: suffix?, text, width.

Variants: none.

Pattern: [message-fold](https://pi-tui.ratstack.sh/patterns/message-fold.md).

Don't: Clip the id suffix after allocating space to the summary.

```
import { Text } from '../../../src/ui/text.ts';
[Text({ suffix: ' · 3abcdefg', text: 'Merlin · The gate is clear', width })]
```

### 40 columns

```text
Merlin · The gate is clear · 3abcdefg
```

### 80 columns

```text
Merlin · The gate is clear · 3abcdefg
```

## Receipt

Mark each delivered recipient without another rat header.

Props: Receipt: lines, theme, width; CompactReceipt: id, parties (party and level), summary?, theme, trimmed, width.

Variants: single recipient: party · summary · id8; multiple: one summary · id8 row, then party · woken|quiet rows.

Pattern: [detail-fold](https://pi-tui.ratstack.sh/patterns/detail-fold.md).

Don't: Put a delivery tick on inbound mail.

```

import { Party } from '../../../src/ui/party.ts';
CompactReceipt({ id: '3abcdefghijk', parties: [{ level: 'woken', party: Party({ label: '🔮 Merlin', name: 'sample/desk', theme }) }], summary: 'The gate is clear', theme, trimmed: false, width })
```

## Box

Close a rounded mail box at every supported width.

Props: body, border, footer?, header, tail?, tag?, theme, width.

Variants: borderless below FRAME_MIN; framed otherwise.

Pattern: [message-fold](https://pi-tui.ratstack.sh/patterns/message-fold.md).

Don't: Hand-draw borders or measure ANSI text with string length.

```
import { Box } from '../../../src/ui/box.ts';
import { Party } from '../../../src/ui/party.ts';
import { Header } from '../../../src/ui/header.ts';
Box({ body: ['The gate is clear.'], border: 'borderMuted', header: Header({ party: Party({ name: 'sample/desk', theme }), theme, variant: 'inbound', verb: 'from' }), theme, width })
```
